# Bundled interface fonts

Fikr Studio bundles the Latin variable-font subsets used by its desktop UI so
production builds are deterministic and never fetch fonts from the network.

- Inter: https://github.com/rsms/inter
- Source Serif 4: https://github.com/adobe-fonts/source-serif
- JetBrains Mono: https://github.com/JetBrains/JetBrainsMono

All three families are distributed under the SIL Open Font License 1.1. The
license text is available at https://openfontlicense.org/open-font-license-official-text/
and in each upstream repository.
